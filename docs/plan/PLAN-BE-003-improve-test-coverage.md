## 背景与目标

### 问题描述

当前后端测试覆盖严重不足：

1. 测试目录为空：tests/ 目录几乎没有有效测试
2. 核心逻辑无测试：业务逻辑缺少单元测试
3. API 测试缺失：接口行为未经验证

### 预期目标

1. 核心模块测试覆盖率达到 70%+
2. 建立测试基础设施
3. API 层测试覆盖所有端点
4. 建立 CI/CD 自动化测试流程

## 测试架构

```
tests/
├── conftest.py                 # 全局 fixtures
├── unit/                       # 单元测试
│   ├── test_notification/
│   ├── test_storage/
│   └── test_services/
├── integration/                # 集成测试
│   └── test_api/
└── fixtures/                   # 测试数据
```
